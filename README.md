# YouTube Ambient Mode Off

A Brave extension that keeps YouTube’s ambient glow off from the first render, including when you open another video in the same tab. It sets YouTube’s native Ambient mode preference to Off for videos and Shorts, and hides the glow layer as a fallback.

## Install in Brave

1. Open `brave://extensions` in desktop Brave.
2. Enable **Developer mode**.
3. Select **Load unpacked** and choose this folder, the one containing `manifest.json`.
4. Reload any open YouTube tabs.

The extension runs only on `www.youtube.com`. To restore the glow, disable the extension, reload YouTube, and turn **Ambient mode** back on in the player settings.
